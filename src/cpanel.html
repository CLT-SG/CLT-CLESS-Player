Text Management

Text Replacement API

Update text content in any text slot across all layouts:

GET /api/replace-text?slotname={slotName}&text={textContent}&freeze_timeout={forever|seconds}
Examples:
https://localhost:9000/api/replace-text?slotname=title&text=Welcome%20to%20eCLESS&freeze_timeout=forever
https://localhost:9000/api/replace-text?slotname=news&text=Breaking%20News!&freeze_timeout=60
Tip: freeze_timeout defaults to forever (layout loop stays on the triggered layout until GET /api/resume-layout). Use a number of seconds for automatic resume.

Freeze & Trigger API

Airport Display Layout + Slot Freeze & TTS Repeat

GET
/api/airport-display/freeze

Read current layout freeze state and documentation.

Layout + Slot property: freeze_timeout — type string|number — default forever. Belongs to Layout + Slot Updates (not TTS).

Values: forever, 0, 30, 60, 120, 300, 600, …

forever: Remain on the triggered layout until GET /api/resume-layout.

TTS property: announcement.repeat — type number — default 1 — max 9. Total plays of the full language sequence (reuse same audio URLs).

Example (layout+slot freeze + TTS repeat): { "layout_id": "12", "slot_id": "45", "slot_type": "media", "value": "boarding.jpg", "freeze_timeout": "forever", "announcement": { "enabled": true, "repeat": 2, "languages": [...] } }
Finite freeze: { "layout_id": "12", "slot_id": "45", "freeze_timeout": 60 }
Status: https://localhost:9000/api/airport-display/freeze
Resume loop: https://localhost:9000/api/resume-layout
GET
/api/resume-layout

Clear Airport Display freeze and resume the normal layout loop (required when freeze_timeout=forever). Does not affect TTS repeat.

TTS Announcements

Airport Display TTS is driven by the announcement object on trigger payloads. Audio URLs are pre-rendered; the player plays languages in order.

Property
announcement.repeat
Type

  "announcement": {

      { "language": "zh", "order": 2, "text": "...", "audio_url": "..." }
    ]
  }
}

announcement.repeat is independent of freeze_timeout. Freeze belongs to Layout + Slot updates.

eCLESS Player API Documentation

The eCLESS Player provides REST API endpoints for programmatic control of the system. Use these URLs to integrate with external systems or automate content management.

Layout Control APIs

GET
/api/update-layout?id={layoutId}

Switch to a specific layout by providing the layout ID.

Example: https://localhost:9000/api/update-layout?id=1

Content Management APIs

GET
/api/replace-text?slotname={slotName}&text={textContent}&freeze_timeout={forever|seconds}

Replace text content in a specific text slot. Optional freeze_timeout freezes the layout loop after the update (default: forever).

Example: https://localhost:9000/api/replace-text?slotname=title&text=Welcome%20to%20eCLESS&freeze_timeout=forever
GET
/api/replace-media?slotname={slotName}&filename={fileName}&freeze_timeout={forever|seconds}

Replace media content in a specific media slot with a file from the resource folder. Optional freeze_timeout (default: forever).

Example: https://localhost:9000/api/replace-media?slotname=video1&filename=promo.mp4&freeze_timeout=60

System Control APIs

GET
/api/shutdown

Shutdown the system immediately.

GET
/api/reboot

Reboot the system immediately.

Example: https://localhost:9000/api/reboot

/api/restartapp

Restart the eCLESS Player application.

Volume Control APIs

Display Control APIs

GET
/api/display/screen/off

Turn off the display screen.

Example: https://localhost:9000/api/display/screen/off
GET
/api/display/screen/on

Turn on the display screen.

Application Control APIs

GET
/api/refresh

Refresh the application display.

Example: https://localhost:9000/api/refresh
GET
/api/screenshot

Capture a screenshot of the current display.

Example: https://localhost:9000/api/screenshot

Important Notes

  • Base URL: All endpoints use https://localhost:9000
  • URL Encoding: Text parameters should be URL encoded (spaces become %20)
  • File Requirements: Media files must exist in the ~/clessapp/res/ directory
  • HTTPS: The API uses HTTPS with self-signed certificates
  • Response: Most endpoints return simple text responses
  • CORS: Cross-origin requests are enabled for web integration
