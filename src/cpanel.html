Layout Switching

Layout Switching API

Use the Update Layout API to programmatically switch between different layouts:

GET /api/update-layout?id={layoutId}
Examples:
https://localhost:9000/api/update-layout?id=1
https://localhost:9000/api/update-layout?id=main-layout
Tip: Layout IDs are shown in the Layout Information section above.
Enter a layout ID from the available layouts to switch to that layout

Text Management

Text Replacement API

Update text content in any text slot across all layouts:

GET /api/replace-text?slotname={slotName}&text={textContent}
Examples:
https://localhost:9000/api/replace-text?slotname=title&text=Welcome%20to%20eCLESS
https://localhost:9000/api/replace-text?slotname=news&text=Breaking%20News!
Tip: Text content must be URL encoded. Spaces become %20, special characters require encoding.

Media Management

Media Replacement API

Replace media files in any media slot with files from your resource folder:

GET /api/replace-media?slotname={slotName}&filename={fileName}
Examples:
https://localhost:9000/api/replace-media?slotname=video1&filename=promo.mp4
https://localhost:9000/api/replace-media?slotname=bg&filename=logo.jpg
Important: Media files must exist in ~/clessapp/res/ directory.

eCLESS Player API Documentation

The eCLESS Player provides REST API endpoints for programmatic control of the system. Use these URLs to integrate with external systems or automate content management.

Layout Control APIs

GET
/api/update-layout?id={layoutId}

Switch to a specific layout by providing the layout ID.

Example: https://localhost:9000/api/update-layout?id=1

Content Management APIs

GET
/api/replace-text?slotname={slotName}&text={textContent}

Replace text content in a specific text slot across all layouts.

Example: https://localhost:9000/api/replace-text?slotname=title&text=Welcome%20to%20eCLESS
GET
/api/replace-media?slotname={slotName}&filename={fileName}

Replace media content in a specific media slot with a file from the resource folder.

Example: https://localhost:9000/api/replace-media?slotname=video1&filename=promo.mp4

System Control APIs

GET
/api/shutdown

Shutdown the system immediately.

Example: https://localhost:9000/api/shutdown
GET
/api/reboot

Reboot the system immediately.

Example: https://localhost:9000/api/reboot
GET
/api/restartapp

Restart the eCLESS Player application.

Example: https://localhost:9000/api/restartapp

Volume Control APIs

GET
/api/volume/mute

Mute the system volume.

Example: https://localhost:9000/api/volume/mute
GET
/api/volume/unmute

Unmute the system volume.

Example: https://localhost:9000/api/volume/unmute
GET
/api/volume/get

Get current volume level (0-100).

Example: https://localhost:9000/api/volume/get

Display Control APIs

GET
/api/display/screen/off

Turn off the display screen.

Example: https://localhost:9000/api/display/screen/off
GET
/api/display/screen/on

Turn on the display screen.

Example: https://localhost:9000/api/display/screen/on

Application Control APIs

GET
/api/refresh

Refresh the application display.

Example: https://localhost:9000/api/refresh
GET
/api/screenshot

Capture a screenshot of the current display.

Example: https://localhost:9000/api/screenshot

Important Notes

  • Base URL: All endpoints use https://localhost:9000
  • URL Encoding: Text parameters should be URL encoded (spaces become %20)
  • File Requirements: Media files must exist in the ~/clessapp/res/ directory
  • HTTPS: The API uses HTTPS with self-signed certificates
  • Response: Most endpoints return simple text responses
  • CORS: Cross-origin requests are enabled for web integration
